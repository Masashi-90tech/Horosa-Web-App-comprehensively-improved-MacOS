# Horosa（星阙）日本語表示パッチ

インストール済みの Horosa（星阙）macOS 版を、**表示だけ**日本語にする差分パッチです。

- アプリ本体・計算エンジン（Python / Java）・保存データには**一切触れません**。
- 画面に表示された中国語の文字を、表示の直前に辞書で日本語に置き換えるだけです。
- 画面左下の小さなボタン（「中文」/「日本語」）で、いつでも原文表示に戻せます。
- 辞書にない文字列は中国語のまま表示されます（翻訳漏れがあっても壊れません）。

| 上部バー・設定メニュー | 新規チャート、チャート一覧、各種設定、AIエクスポート設定、全体設定 など |

| 西洋占星の基本用語 | 天体・サイン・ハウス・品位などの名前（画面の文字として出る箇所） |
| 共通のボタン・メッセージ | OK / キャンセル / 保存 / 削除 / 読み込み中… など |
| 起動・接続の画面 | 「ローカルサービスに接続中…」、接続エラーやチャート作成失敗のメッセージ |

## v0.2.1 の追加

- **紫微斗数の解説ポップアップ**（宮・星・四化にマウスを重ねると出る説明）921文を日本語に訳しました。
- **星盤（図）の中の文字**は、字体だけ日本式にします（例：七杀→七殺、天钺→天鉞、迁移→遷移）。文字数が変わらないので図の配置は崩れません。
- **辞書にまだ無い文字列**も、簡体字を1文字ずつ日本の字体にします（例：运势→運勢）。文脈で字が変わる字（后・干・发 など）は変換しません。

訳語の一覧は [GLOSSARY.md](GLOSSARY.md) を見てください。

### わざと訳していないもの

- **星盤（チャート図）の中の文字**：訳は入れず、字体だけ日本式にします（図の配置を崩さないため）。Canvas で描かれた図は対象外です。
- **干支・神殺など中国術数の用語**（甲子、天乙、白虎…）：日本でも同じ漢字で通じるため、そのままです。
- **紫微斗数・四柱推命と意味が衝突する語**（宫位、格局、陷 など）：全画面に効く辞書には入れていません。
- **入力欄に入っている値**、エディタの中身。
- **起動ランチャー画面**（デスクトップアプリの外枠）：アプリ本体のバイナリに埋め込まれていて、パッチでは差し替えられません。
- **計算サーバーが返す判断文**、タロットのカードの意味など、データとして入っている文章：対象外です。
- **30字を超える長い説明文**（約1,700種類）と、実行時に組み立てられる文：一部だけ訳しています。

## 導入方法（Mac）

1. この `i18n-ja` フォルダ（または配布された zip を展開したフォルダ）を Mac に置きます。
2. **Horosa（星阙）を終了**します（⌘Q）。
3. 「ターミナル」を開き、`bash ` （最後に半角スペース）と入力してから、
   `install_ja_patch.command` をターミナルにドラッグ＆ドロップして Enter を押します。
   ```
   bash /Users/あなたの名前/Downloads/horosa-ja-patch-v0.3.2/install_ja_patch.command
   ```
   - ダブルクリックだと「Apple は…マルウェアが含まれていないことを検証できませんでした」と出て開けません
     （署名のないスクリプトに対する macOS の標準の動作です）。ターミナルから `bash` で実行すればこの確認は出ません。
   - 「書き込み権限がありません」と出たら、表示された `sudo bash …` の行を実行してください。
4. 「完了しました」と出たら Horosa を起動します。日本語で表示されます。

インストーラが行うのは次の2つだけです。

- アプリの画面ファイルのフォルダ（`…/runtime/current/Horosa-Web/astrostudyui/dist-file/`）に `horosa-i18n/` を置く
- 同じフォルダの `index.html` の `</head>` の直前に、読み込みタグを1行足す（元のファイルは `index.html.before-horosa-ja` として保存）

対象のフォルダは次の2か所です（存在するほうだけ）。

- `/Users/Shared/Horosa/runtime/current`
- `~/Library/Application Support/com.horacedong.horosa/runtime/current`

## 使い方

- 画面左下の **「中文」** ボタン → 原文（中国語）表示に切り替え（画面を再読み込みします）
- 中国語表示のときは同じ場所が **「日本語」** ボタンになります
- 選んだ言語は記憶されます

## 元に戻す

Horosa を終了してから、導入時と同じくターミナルで `bash` に続けて `uninstall_ja_patch.command` をドラッグして実行します。追加した1行とフォルダだけを取り除くので、`index.html` は元の内容に戻ります。

## アプリをアップデートしたとき

Horosa のアップデートで画面ファイルが丸ごと入れ替わるため、**パッチは外れます**（アプリは普通に動きます）。もう一度 `install_ja_patch.command` を実行してください。パッチは特定のバージョンに依存しないので、そのまま使えます。

## 仕組みと安全性

```
React（アプリ本体）が画面を描く
        │  ← ここで MutationObserver が変化を検知（描画が画面に出る前のタイミング）
        ▼
表示された「文字」だけを辞書で置換 ──→ 画面には日本語が出る
（データ・状態・計算・通信は元の中国語のまま）
```

- アプリのコードの中では、中国語の文字列が計算用のキーとしても使われています（例：`if(god === '天乙')`）。
  そのため**ソースコードの中国語を書き換える方式は採らず**、画面に出た文字だけを置き換えています。計算結果は構造上変わりません。
- 段落の中に太字などが混ざる解説文は、React が管理する要素を動かさずに原文を CSS で隠し、訳文を横に重ねて表示します。
  原文が変われば訳文も自動で張り直します。
- 翻訳処理でエラーが起きてもアプリは止まりません（警告を出して処理を飛ばします）。

### 既知の制限

- ナビゲーションの検索は、内部のキーワードが中国語のままなので、日本語では引っかからないことがあります。
- 解説の文章をコピーすると、隠している原文が一緒にコピーされることがあります。
- AIエクスポートなど、アプリが内部データから作る文章は中国語のままです。

## 開発者向け

```
i18n-ja/
├── install_ja_patch.command / uninstall_ja_patch.command   … Mac 用の導入・削除スクリプト
├── patch/horosa-i18n/horosa-ja.js   … 配布物（ビルド結果。エンジン＋辞書を1ファイルにまとめたもの）
├── src/engine.js, src/shared.js     … 翻訳エンジン
├── dict/ui/*.json                   … UI 辞書（{ セクション: { 中文: 日本語 } }）
├── dict/scoped.json                 … 場所を限定する辞書（1文字の語など）
├── dict/patterns.json               … 正規表現による置換（「10 条/页」など）
├── dict/help/*.json                 … 解説ページの段落単位の辞書（⟦n|…⟧ は太字などの子要素）
├── GLOSSARY.md                      … 用語対照表（自動生成）
└── tools/                           … 抽出・ビルド・検査・ブラウザテスト
```

```bash
cd i18n-ja/tools && npm install && cd ../..
# 解説ページから翻訳単位を抽出（既存の訳は引き継ぐ）
node i18n-ja/tools/extract-help.mjs Horosa-Web/astrostudyui/src/components/help/AstroHelpDoc.js i18n-ja/dict/help/astro.json
# 「番号<TAB>訳文」形式の訳を取り込む
node i18n-ja/tools/merge-tsv.mjs i18n-ja/dict/help/astro.json 訳.tsv
# 簡体字の混入チェック → ビルド（辞書の衝突があると失敗）→ 実ブラウザでのテスト
node i18n-ja/tools/check-ja.mjs
node i18n-ja/tools/build.mjs
node i18n-ja/tools/browser-test.mjs
# 本物のフロントエンドで確認（Horosa-Web/astrostudyui で npm ci && npm run build:file の後）
node i18n-ja/tools/app-smoke.mjs Horosa-Web/astrostudyui/dist-file
```

`browser-test.mjs` はアプリと同じ版の React 17 / antd 4.24 とデスクトップ版と同じ CSP で、
翻訳・再描画・アンマウント・言語切替・SVG や入力欄を訳さないことなど約30項目を検査します。
`app-smoke.mjs` は本物のビルド結果に本物のインストーラでパッチを当て、計算サーバーなしで画面を開いて
未翻訳の文字列と JavaScript のエラーを報告します。

開発中は、ブラウザのコンソールで `__HOROSA_I18N__.debugMissing()` を実行してから画面を操作し、
`__HOROSA_I18N__.dumpMissing()` を実行すると、辞書にない中国語の一覧が取れます。
